## 1. Подготовка окружения и ветки Git

## 3. Технические требования к модулю `src/password_validator.py`

Функция `validate_password(password: str) -> bool` должна соответствовать следующим критериям:

### 3.1. Генерация исключений (Первый этап)
1. **Исключение `TypeError`:** Выбрасывается, если тип аргумента `password` не является `str` (`raise TypeError("Пароль должен быть строкой")`).
2. **Исключение `ValueError`:** Выбрасывается при наличии хотя бы одного символа пробела в любой части строки (`raise ValueError("Пароль не должен содержать пробелы")`).

### 3.2. Правила валидации (Второй этап)
Возвращает `True` только при одновременном выполнении следующих условий:
1. **Длина:** $8 \le \text{len}(password) \le 20$.
2. **Заглавные буквы:** Содержит минимум одну заглавную букву (латиница или кириллица, метод `.isupper()`).
3. **Строчные буквы:** Содержит минимум одну строчную букву (латиница или кириллица, метод `.islower()`).
4. **Цифры:** Содержит минимум одну цифру ($0-9$, метод `.isdigit()`).
5. **Специальные символы:** Содержит минимум один символ из спец-набора:
   $$\Sigma_{\text{spec}} = \{ \texttt{!}, \texttt{@}, \texttt{\#}, \texttt{\$}, \texttt{\%}, \texttt{\^}, \texttt{\&}, \texttt{*} \}$$

## 4. Запуск и отладка тестов

### 4.1. Запуск модульного тестирования (`unittest`)
Запустите автообнаружение и выполнение всех тестов из папки `tests`:

```bash
python -m unittest discover -s tests -v
```

Все тестовые кейсы должны завершаться вердиктом `OK`.

---

## 5. Проверка покрытия кода тестами (`coverage`)

Для оценки полноты покрытия кода тестами используется утилита `coverage`.

### 5.1. Установка `coverage` (при необходимости)
```bash
pip install coverage
```

### 5.2. Сбор и формирование отчёта
Запустите сбор статистики и выведите итоговый отчёт в консоль:

```bash
python -m coverage run --source=src -m unittest discover -s tests -v
python -m coverage report -m
```

### 5.3. Критерий успешности
Покрытие файла `src/password_validator.py` должно быть строго **100%**:

```text
Name                        Stmts   Miss  Cover   Missing
---------------------------------------------------------
src/__init__.py                 0      0   100%
src/password_validator.py      12      0   100%
---------------------------------------------------------
TOTAL                          12      0   100%
```

## 6. Сохранение и отправка изменений в Git

### 6.1. Проверка статуса рабочей директории
```bash
git status
```

Убедитесь, что кэш Python (`__pycache__`), служебные файлы `.coverage`, виртуальное окружение или настройки IDE не попали в статус отслеживаемых.

### 6.2. Индексация и коммит
Добавьте только необходимые файлы и сформируйте коммит:

```bash
git add src/password_validator.py tests/test_password_validator.py
git commit -m "feat: implement password validator and unit tests"
```

### 6.3. Отправка ветки в удалённый репозиторий
```bash
git push -u origin cut_knowelage
```
